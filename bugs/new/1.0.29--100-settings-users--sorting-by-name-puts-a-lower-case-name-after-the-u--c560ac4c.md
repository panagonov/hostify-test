# QA-533 · 100-settings-users — sorting by Name puts a lower-case name after the upper-case ones

- Версия на приложението: **1.0.29** · Акаунт: QA Automation · Намерен в пуска 2026-11-26_09-58-21
- Спек: `tests/e2e/100-settings-users.spec.ts` — Settings › Users — по един потребител на роля през формата; всеки влиза с известната парола
- Папка на пуска: [reports/issues/1.0.29/2026-11-26 09:58](../../reports/issues/1.0.29/2026-11-26%2009:58)

**Какво се обърка**

Settings › Users, сортиране по Name във възходящ ред: „admin (staff)“ (малка буква) стои СЛЕД „QA Team Supervisor“
(главни букви) — редовете 8 и 9. Сортирането различава главни и малки букви (кодова таблица), а човек очаква азбучен
ред без значение от буквите: „admin…“ преди „QA …“. Нисък приоритет — данните са верни, само редът.

**Как се възпроизвежда**

1. Влез като администратор на QA Automation.
2. Settings › Users; в акаунта да има човек, чието име започва с малка буква (тук: служителят на поддръжката от staff сесия).
3. Натисни сортирането на колоната Name (възходящо) — „admin (staff)“ е след всички „QA …“.
