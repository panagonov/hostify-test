# QA-541 · 220-pricing-fee-templates — after the server refuses a Save, the form is emptied — everything typed is lost

- Версия на приложението: **1.0.36** · Акаунт: QA Automation · Намерен в пуска debug-2026-11-27
- Спек: `tests/e2e/220-pricing-fee-templates.spec.ts` — Pricing › шаблон за такси през формата
- Папка на пуска: [test-results](../../test-results)

**Какво се обърка**

Когато сървърът откаже Save (грешка, показана като съобщение горе), формата **се изчиства**: всичко въведено изчезва и формата
казва, че задължителните полета са празни. Човек трябва да въвежда всичко наново, а не да поправи едното поле. Видяно на две
форми, на две версии:

- Settings › VATs › „Create a new vat rate“ (1.0.35): Rate (%) = −5 → сървърът отказва (−496 „The rate does not match its
  type“) → формата е празна („4 fields are required before this record can be saved“), името също го няма;
- Pricing › Fees › „Create a new fee template“ (1.0.36): без ред на такса → сървърът отказва („A template needs at least one fee
  line“) → Name, Type, Currency, Country, Status са празни.

Очаквано: при отказ формата остава с въведеното и казва кое поле да се поправи. Среден приоритет.

**Как се възпроизвежда**

1. Settings › VATs → „Create a new vat rate“: Name „QA VAT test“, Rate −5, Rate type Standard, Status Active → Save.
2. Сървърът отказва; формата е празна. Cancel.
