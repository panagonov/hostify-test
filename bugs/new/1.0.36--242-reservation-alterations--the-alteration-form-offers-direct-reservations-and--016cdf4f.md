# QA-543 · 242-reservation-alterations — the alteration form offers DIRECT reservations, and only the server refuses them (-666 „only for channel reservations“)

- Версия на приложението: **1.0.36** · Акаунт: QA Automation · Намерен в пуска debug-2026-11-27
- Спек: `tests/e2e/242-reservation-alterations.spec.ts` — Reservations › Alterations — формата и отказът за директна резервация
- Папка на пуска: [test-results](../../test-results)

**Какво се обърка**

Reservations › Alterations › „Create a new reservation alteration“: полето Reservation предлага и **директни** резервации. Чак
след попълване на всичко Save получава от сървъра: „Bad Request -666 — Alteration requests can only be sent for channel
reservations.“ (и формата се изчиства — виж QA-541). Очаквано: формата да предлага само резервации от канал (или да казва това
веднага, щом се избере директна).

**Как се възпроизвежда**

1. Администратор на QA Automation; директна резервация на наш гост.
2. Alterations → Create: Reservation = тази резервация, Origin, New check in / out → Save.
3. Сървърът отказва с -666. Cancel.

Видяно в пробите на спек 242 (2026-11-27, 1.0.36).
