# QA-542 · 250-calendar — Update Calendar sometimes opens with the start of the Period empty, and Save stays disabled without saying why

- Версия на приложението: **1.0.36** · Акаунт: QA Automation · Намерен в пуска debug-2026-11-27
- Спек: `tests/e2e/250-calendar.spec.ts` — Calendar — блокиране и цена през „Update Calendar“
- Папка на пуска: [test-results](../../test-results)

**Какво се обърка**

Calendar → избор на нощи с влачене (напр. 06–07.12) → More → „Update Calendar“: заглавието казва „1 listing(s) · 2026-12-06 →
2026-12-07“, но в полето **Period началото е празно** (само „End date“ е попълнено). Save е неактивен и **не казва защо** (няма
съобщение до полето). Човек не разбира какво липсва. (Отделно: при Availability „Blocked“ полето „Block reason“ е задължително —
и то без подсказка, докато не се погледне.)

**Как се възпроизвежда**

1. Администратор на QA Automation, Calendar; обява без резервации на тези дни.
2. Влачи върху две свободни нощи → More.
3. Виж Period: началото е празно; избери Blocked — Save остава неактивен без обяснение. Cancel.

Видяно в пробите на спек 250 (2026-11-27, 1.0.36); тестът попълва началото на периода сам.
