# QA-505 · 112-telemetry-own-only — the refused Telemetry page (404) is titled „Settings / Users“

- Версия на приложението: **1.0.28** · Акаунт: QA Automation · Намерен в пуска 2026-11-25_15-14-51
- Спек: `tests/e2e/112-telemetry-own-only.spec.ts` — Telemetry — booking agent и housekeeper не виждат чужда Telemetry (по адрес и през API); само гледане
- Папка на пуска: [reports/issues/1.0.28/2026-11-25 15:14](../../reports/issues/1.0.28/2026-11-25%2015:14)

**Какво се обърка**

Booking agent (и housekeeper) отваря по адрес `/app/settings/users/<id на администратора>/telemetry`. Приложението
правилно отказва с „Error 404 — Page not found“, но заглавието горе вляво остава „Settings / Users — People who can sign
in, with their roles and status“: страницата, до която човекът няма достъп, се назовава. Очаквано: заглавие на 404
(или никакво), не името на отказаната страница. Нисък приоритет — данни не се показват.

**Как се възпроизвежда**

1. Влез като booking agent на акаунта QA Automation (qa.booking.agent@hostify-qa.test).
2. Отвори https://hostify.bioseek.eu/app/settings/users/<id на администратора>/telemetry.
3. Виж заглавието горе вляво при екрана „Error 404“.

Видяно в пуска 2026-11-25_15-14-51 (1.0.28), снимка `reports/runs/2026-11-25_15-14-51/112_bookingAgent_…_shot-bookingAgent-admin-telemetry.png`.
