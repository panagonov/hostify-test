# QA-534 · map-step1 — Roles: the role form has no required Name — Save on an empty form sends the request

- Версия на приложението: **1.0.29** · Акаунт: QA Automation · Намерен в пуска map-2026-11-26
- Спек: `tests/e2e/map-step1.spec.ts` — Стъпка 1 — карта на формите (headless, само гледане; Save на празна форма — записът е спрян; Cancel)
- Папка на пуска: [reports/test-scenarios/forms-map.md](../../reports/test-scenarios/forms-map.md)

**Какво се обърка**

Формата за нова роля няма нито едно задължително поле (нито Name на един от четирите езика). Save на празната форма изпраща заявката към сървъра без проверка в браузъра (в картата заявката беше спряна от режима „само гледане“ — нищо не е записано). Очаквано: Name е задължително и празна роля се отказва още във формата.

**Как се възпроизвежда**

1. Влез като администратор на QA Automation.
2. Settings › Roles (`/app/settings/securityGroups`) → „Create a new security group“.
3. Виж формата; Cancel. (Нищо не се записва.)
