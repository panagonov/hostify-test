## Fix

**Какво беше грешно:** бутонът с лупата на Search полетата (Account, Role, Default account, Owner) беше притиснат до
34px от общото правило за бутони на Hostify, а полетата в drawer формите са 40px; бутонът „генерирай“ в Password
вземаше големия размер на формата (40px) и раздуваше полето до 56px.

**Какво е променено:**
- Hostify, `client/src/hydraExtension/styles/ButtonExtension.scss` — бутонът, който е част от поле (`.ant-input-search-btn`),
  взема височината на полето (34px или 40px), вместо 34px на самостоятелен бутон.
- Енджин, клиент `client/main` 1.5.127 — `PasswordGenerator.tsx`: бутонът „генерирай“ в полето е `size="small"`.
- Тест: e2e `tests/e2e/platformAdminUsers.spec.ts` › „the Create user form: a search field is one control and Password
  has the form's height“ (червен преди поправката: „tenant: the magnifier 34px beside a 40px field“, зелен след нея).
- Отделно (същата форма): секциите Scope и Owner portal вече следват ролята — Owner portal се вижда само при Property
  Owner, Scope не се вижда при Support / Super admin (build-config 1.0.75).

**Кое издание го носи:** следващото издание на Hostify след 1.0.5 (build-config 1.0.75, енджин client/main 1.5.127) —
нужни са build и deploy.

**Как го вижда QA:** спек `006-platform-admin-users`, проверка „the Create user form opens, every tab is presentable,
an empty Save is refused“ — без `field-parts` и `field-height` грешки.
