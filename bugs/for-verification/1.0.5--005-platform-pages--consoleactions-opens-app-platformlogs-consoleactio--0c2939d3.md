## Fix

- **Какво беше:** страницата Platform Logs › Console actions искаше списъка с акаунти с `POST /tenant/search` (нейният
  помощник `call()` праща всичко с POST), а търсенето на Hydra API е GET — сървърът отговаряше 404 „Cannot POST“ и
  списъкът с акаунти оставаше празен.
- **Какво е променено:** `client/src/page/ConsoleActions.tsx` чете акаунтите през генерирания GET
  `api.tenant.searchTenant({size: 100, sort: "name^ascend"})`. Клиент 1.5.128 (`client/CHANGELOG.md`). Тест, червен
  преди поправката: `tests/unit/client/platformAdmin/consoleActionsAccounts.test.ts`.
- **Носи го:** следващият деплой на клиента (версия на приложението след 1.0.5).
- **Как се вижда:** спек 005-platform-pages, проверка „consoleActions opens“ — без 404 в мрежата; падащият списък с
  акаунти на страницата е пълен.
