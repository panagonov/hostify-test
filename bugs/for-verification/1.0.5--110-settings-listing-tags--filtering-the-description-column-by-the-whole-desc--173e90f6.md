## Fix

**Какво беше грешно:** текстовият филтър на колона (`_text`) търсеше думите на фразата с оператор OR в полето с
edge-ngram индекс — стигаше една къса дума: „a“ е началото на „are“, затова „Pets are welcome“ оставаше.

**Какво е променено:**
- Енджин, `es_db` 1.1.11 — `SearchQueryBuilder.ts`: филтърът `_text` изисква всяка дума (`operator: "and"`); филтър от
  една дума и глобалното търсене не са променени.
- Тест: `es_db/tests/searchQueryBuilder.text.test.ts` (червен преди поправката: „the words are OR-ed“, зелен след нея).
- Проверено локално през API-то на Listing tags: „Listings with a view to the sea“ → само „Sea view“; „pets welcome“ →
  само „Pet friendly“.

**Кое издание го носи:** следващото издание на Hostify след 1.0.5 (енджин es_db 1.1.11) — нужни са build и deploy
(сървърът).

**Как го вижда QA:** спек `110-settings-listing-tags`, проверка „filtering the Description column by the whole
description of one tag leaves only that tag“ — остава само тагът „Sea view“.
